## Критерии завершения проекта

Платформа считается реализованной, когда она:

- получает данные из нескольких независимых источников;
- сохраняет оригиналы и историю обновлений;
- хранит большие наборы данных в Parquet в S3;
- использует PostgreSQL для метаданных и управления загрузками;
- выполняет нормализацию, проверку качества и сопоставление данных;
- строит аналитические витрины через dbt и DuckDB;
- автоматически запускает конвейеры данных через Airflow;
- выполняет орбитальные расчёты через SGP4;
- предоставляет данные через FastAPI;
- контролирует качество, актуальность и состояние процессов.

## Принципы разработки

1. Каждый подэтап должен завершаться работающим результатом.
2. Перед внедрением новой технологии необходимо разобраться в её назначении.
3. Для каждого этапа предусматриваются тесты и краткая техническая
   документация.
4. Исходные данные Bronze не изменяются: обработанные наборы формируются
   независимо.
5. Архитектура развивается постепенно, без преждевременного усложнения.
