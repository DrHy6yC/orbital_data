# CelesTrak

## 1. Подключение к источнику

- **Официальный сайт:** https://celestrak.org/
- **API:** https://celestrak.org/NORAD/elements/gp.php
- **Документация API:** https://celestrak.org/NORAD/documentation/gp-data-formats.php
- **Документация SupGP:** https://celestrak.org/NORAD/documentation/sup-gp-queries.php
- **Список доступных групп:** https://celestrak.org/NORAD/elements/
- **Правила использования:** https://celestrak.org/usage-policy.php

### 1.1. Авторизация

- Регистрация: не требуется.
- Авторизация: не требуется.
- Данные доступны через открытый HTTP API.

### 1.2. Способ получения данных

- **Тип подключения:** HTTP API.
- **HTTP-метод:** GET.
- **Способ получения:** запросы с параметрами.
- **Основные параметры:** `GROUP`, `CATNR`, `INTDES`, `NAME`, `SPECIAL`.
- **Форматы ответа:** CSV, JSON, JSON-PRETTY, XML, KVN, TLE, 3LE, 2LE.

Пример запроса:

```text
https://celestrak.org/NORAD/elements/gp.php?GROUP=STATIONS&FORMAT=JSON
```

## 3. Ограничения

- Данные GP обновляются с периодичностью, установленной источником.
- Не следует отправлять избыточные запросы.
- Необходимо соблюдать правила использования API.
- Чрезмерное количество запросов и повторяющиеся ошибки могут привести к блокировке IP-адреса.
- При HTTP 429 необходимо учитывать `Retry-After`, если он предоставлен.
- При ошибках авторизации или запрета доступа необходимо прекратить дальнейшие запросы до выяснения причины.
- TLE и 3LE имеют ограничение на пятизначный номер каталога. Для новых объектов следует использовать OMM-совместимые форматы, например JSON или CSV.
