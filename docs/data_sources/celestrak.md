# CelesTrak

## 1. Подключение к источнику

- **Официальный сайт:** https://celestrak.org/
- **API:** https://celestrak.org/NORAD/elements/gp.php
- **Документация API:** https://celestrak.org/NORAD/documentation/gp-data-formats.php
- **Документация SupGP:** https://celestrak.org/NORAD/documentation/sup-gp-queries.php
- **Список доступных групп:** https://celestrak.org/NORAD/elements/
- **Правила использования:** https://celestrak.org/usage-policy.php

### 1.1. Авторизация

- Регистрация: не требуется.
- Авторизация: не требуется.
- Данные доступны через открытый HTTP API.

### 1.2. Способ получения данных

- **Тип подключения:** HTTP API.
- **HTTP-метод:** GET.
- **Способ получения:** запросы с параметрами.
- **Основные параметры:** `GROUP`, `CATNR`, `INTDES`, `NAME`, `SPECIAL`.
- **Форматы ответа:** CSV, JSON, JSON-PRETTY, XML, KVN, TLE, 3LE, 2LE.

Пример запроса:

```text
https://celestrak.org/NORAD/elements/gp.php?GROUP=STATIONS&FORMAT=JSON
```

### 2.4. Сверка форматов JSON и CSV

Проверено скриптом `utils/compare_formats.py` 2026-11-15 на группах `STATIONS`
(17 объектов) и `ANALYST` (575 объектов), по одному запросу на каждую пару
«группа + формат».

| Показатель | JSON | CSV |
|---|---|---|
| Content-Type | application/json | text/plain |
| Размер, `STATIONS` / `ANALYST`, байт | 7208 / 233035 | 2823 / 78055 |
| Отношение размера JSON к CSV | 2,55 / 2,99 | |
| Число полей | 17 | 17 |
| Типы значений | числа и строки; в одном поле встречаются `int` и `float` | только строки |
| Пустые значения | пустая строка, `null` нет | пустая строка |
| Расхождения значений | 0 из 289 и 0 из 9775 | |

Особенности:
- Состав полей одинаков. Постоянных полей OMM (`CENTER_NAME`, `REF_FRAME`,
  `TIME_SYSTEM`, `MEAN_ELEMENT_THEORY`) в ответах нет.
- `EPOCH` передаётся без часового пояса (время UTC).
- В `ANALYST` у всех записей пустой `OBJECT_ID`.
- Номера от 100000 есть в обоих форматах (максимум 270449).

**Вывод:** для CelesTrak используется CSV: данные идентичны JSON, размер втрое
меньше, формат рекомендован источником. Типы задаются схемой при разборе.

## 3. Ограничения

- Данные GP и SupGP обновляются раз в 2 часа; скачивать один раз за обновление.
- Страницы `jsonDir.php` (проверка наличия обновлений) запрашивать не чаще 1 раза в час.
- При любом ответе, отличном от HTTP 200 (301, 403, 404, 50x), немедленно прекратить запросы и вызвать исключение Повторные попытки не выполняются.
- Ограничения принудительно применяются к большим наборам (`active`, `starlink`).
- Чрезмерное количество запросов приводит к блокировке IP-адреса.
- Неизвестная группа возвращает HTTP 200 и текст `Invalid query`. Это ошибка
  запроса, а не ограничение частоты: отказ по лимиту приходит с другим кодом
  ответа.
- TLE и 3LE имеют ограничение на пятизначный номер каталога. Для новых объектов следует использовать OMM-совместимые форматы, например JSON или CSV.
