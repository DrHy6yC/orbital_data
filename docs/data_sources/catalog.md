# Справочник источников данных

Документ содержит перечень источников данных, используемых в Orbital Data Platform, и ссылки на их техническое описание.

## 1. Источники данных

| Источник | Описание | Доступ |
|---|---|---|
| [CelesTrak](celestrak.md) | Орбитальные данные искусственных спутников и других космических объектов | Открытый API, регистрация не требуется |
| [Space-Track](space_track.md) | Орбитальные данные, каталог космических объектов и исторические сведения | API, требуется регистрация и авторизация |

## 2. Назначение источников

### CelesTrak

Предоставляет открытый доступ к орбитальным данным через HTTP API.

Основные наборы:
- GP — актуальные орбитальные данные.
- SupGP — дополнительные орбитальные данные.
- Группы объектов по назначению и принадлежности.

### Space-Track

Предоставляет доступ к данным о космических объектах через REST API.

Основные наборы:
- GP — актуальные орбитальные данные.
- GP_HISTORY — история орбитальных элементов.
- SATCAT — каталог космических объектов.
- DECAY — сведения о сходе объектов с орбиты.
- TIP — сообщения о прогнозируемом сходе объектов.
