# Наборы данных для первоначальной загрузки

Выбор наборов для этапа 3. Остальные группы и классы API из описаний источников
добавляются по мере необходимости.

## 1. Выбранные наборы

| № | Источник | Набор | Формат | Частота загрузки | Каталог в `data/` |
|---|---|---|---|---|---|
| 1 | CelesTrak | GP, группа `stations` | CSV | не чаще 1 раза в 2 часа | `data/celestrak/gp_stations/` |
| 2 | CelesTrak | GP, группа `active` | CSV | не чаще 1 раза в 2 часа | `data/celestrak/gp_active/` |
| 3 | Space-Track | `GP` | JSON | не чаще 1 раза в час | `data/space_track/gp/` |
| 4 | Space-Track | `SATCAT` | JSON | 1 раз в день после 17:00 UTC | `data/space_track/satcat/` |
| 5 | Space-Track | `DECAY` | JSON | 1 раз в день | `data/space_track/decay/` |

## 2. Причины выбора

- **CelesTrak `stations`** — маленький набор (МКС и другие станции) для отладки загрузчика без нагрузки на источник.
- **CelesTrak `active`** — полный набор активных спутников для реальной нагрузки на хранилище и обработку.
- **Space-Track `GP`** — основной источник актуальных орбитальных элементов, второй независимый источник для сопоставления (этап 5.7).
- **Space-Track `SATCAT`** — каталог объектов, основа единого каталога (этап 5.3).
- **Space-Track `DECAY`** — сведения о сходе с орбиты, нужны для истории и аналитики.

## 3. Что не берём на первом этапе

- `starlink` и другие группы CelesTrak: входят в `active`, отдельная загрузка дублировала бы данные.
- `GP_HISTORY`: допускается один раз на объект, поэтому загружается позже, отдельной задачей, с обязательным локальным хранением.
- `TIP`, `CDM`, `BOX_SCORE`, `60_DAY_DECAY`, `SATCAT_DEBUT`: не нужны для первых этапов.
- TLE и 3LE: ограничение на пятизначный номер каталога.

## 4. Ограничения

- Лимиты Space-Track: менее 30 запросов в минуту и менее 300 в час; один запрос на набор, идентификаторы объектов объединяются.
- Частота для CelesTrak (раз в 2 часа) подтверждена правилами использования. При любом ответе, кроме HTTP 200, запросы прекращаются без повторов.
- Формат CelesTrak: CSV, выбран по результатам сверки (см. `celestrak.md`, раздел 2.4). Для Space-Track выбран JSON.

## 5. Фактические размеры ответов

Измерены 2026-11-15 при полном прогоне:

| Набор | Размер | Формат |
|---|---|---|
| CelesTrak `stations` | 2,7 КБ | CSV |
| CelesTrak `active` | 2,4 МБ | CSV |
| Space-Track `GP` | 75,7 МБ | JSON |
| Space-Track `SATCAT` | 31,9 МБ | JSON |
| Space-Track `DECAY` | 41,3 МБ | JSON |

Полный прогон даёт около 152 МБ. При часовой загрузке `GP` это около
1,8 ГБ в сутки, поэтому частоту и способ хранения нужно уточнить на этапе
организации хранилища.
