5. Принцип дальнейшего развития
Сейчас фиксируем только три вещи:
1. Куда подключаемся — адрес источника, API и документация.
2. Как подключаемся — авторизация и способ получения данных.
3. Что получаем — доступные наборы и их форматы.
Когда перейдём к этапу 3, будем дополнять документацию реальными примерами запросов, параметрами, ответами API и обнаруженными ограничениями.
