## Активная задача

### 3.2. Реализация загрузки

**Файл и место:** `src/orbital_data/collectors/download.py` (новый модуль),
`utils/check_download.py`, `tests/test_download.py`.

**Что нужно сделать:** добавить функцию получения исходных ответов по
наборам из `datasets.md`: CelesTrak `STATIONS` и `ACTIVE` (CSV) через
`fetch_gp`, Space-Track `GP`, `SATCAT` и `DECAY` (JSON) через `fetch`.
Запросы последовательные, по одному на набор: идентификаторы объектов не
перечисляются, исходный формат ответа не меняется.

**Учесть:**
- результат — тела ответов без преобразования, ключ набора в словаре,
  плюс ошибки источников отдельным словарём;
- источники независимы: при `SourceStopped` оставшиеся наборы этого
  источника не запрашиваются, второй источник загружается;
- пауза между запросами и контроль частоты — задача 3.3;
- запись файлов в `data/` — задача 3.4.

**Ожидаемый результат:** одна функция, которая получает все пять наборов
и возвращает загруженные ответы и ошибки источников.

**Как проверить:**
- `tests/test_download.py` на `httpx.MockTransport`: состав и порядок
  запросов, остановка упавшего источника, загрузка второго источника;
- живой прогон всех пяти наборов после истечения окон частоты: CelesTrak —
  2 часа с прошлого запроса набора, Space-Track `GP` — 1 час;
- живой прогон выполняется командой
  `uv run --env-file .env python utils/check_download.py`.
