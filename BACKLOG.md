## Активная задача

### 2.3. Выбор наборов данных

**Файл и место:** `docs/data_sources/datasets.md`

**Что нужно сделать:**
1. Запустить `uv run python utils/compare_formats.py` (по одному запросу на каждую пару «группа + формат») и изучить отчёт в `data/celestrak/responses/`.
2. Выбрать наборы для первоначальной загрузки из `celestrak.md` и `space_track.md`. Кандидаты:
   - CelesTrak GP: `stations`, `active`, при необходимости `starlink`;
   - Space-Track: `GP`, `SATCAT`, при необходимости `DECAY`.
3. Для каждого набора зафиксировать источник, группу или класс API, формат (JSON или CSV, не TLE), допустимую частоту запросов, каталог в `data/` и причину выбора.
4. Внести выводы сверки JSON и CSV в `celestrak.md`.

**Ожидаемый результат:** список наборов для первоначальной загрузки с форматами и частотой обновления.

**Как проверить:**
- для каждого набора заполнены все поля из пункта 3;
- частота загрузки не превышает лимитов источников;
- выводы сверки форматов отражены в `celestrak.md`.

## Активная задача

### 3.1. Реализация подключения к источникам

**Файл и место:** `src/orbital_data/` (структуру определить при переходе к задаче).

**Что нужно сделать:** подключение к CelesTrak (без авторизации), затем к Space-Track (логин, сессия, учётные данные из `.env`). Выбрать HTTP-клиент: `urllib` или `httpx`.

**Учесть:**
- CelesTrak: любой ответ, кроме HTTP 200, останавливает запросы без повторов;
- Space-Track: тайм-ауты, 429 с `Retry-After`, 5xx с ограниченным числом повторов, остановка при 403.

**Ожидаемый результат:** оба источника доступны через программный интерфейс.

**Как проверить:** по одному тестовому запросу к каждому источнику с успешным ответом.
