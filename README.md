# Orbital Data Platform

Lakehouse-платформа для сбора, хранения, обработки и анализа данных об искусственных спутниках и орбитальных объектах.

## Цель проекта

Создать воспроизводимую платформу данных с сохранением истории изменений, контролем качества и возможностью повторной обработки исходных данных.

## Источники данных

- CelesTrak: TLE и OMM, открытый доступ.
- Space-Track: GP, GP_History, SATCAT, требуется регистрация.

    orbital_data/

## Требования

- Python 3.12 или новее
- uv

## Запуск проекта

Установка зависимостей:

```powershell
uv sync
```

Запуск тестов:

```powershell
uv run pytest
```

## Технологический стек

- **Python 3.12+** — основной язык разработки.
- **uv** — управление зависимостями и окружением.
- **FastAPI** — REST API.
- **PostgreSQL** — метаданные и операционная информация.
- **MinIO (S3)** — хранение исходных данных.
- **Parquet / PyArrow** — аналитическое хранение.
- **DuckDB / dbt** — аналитическая обработка.
- **Apache Airflow** — оркестрация процессов.
- **SGP4 / Skyfield** — орбитальные вычисления.

## Архитектура данных

Платформа использует архитектуру Lakehouse:

- **Bronze** — исходные данные без изменений.
- **Silver** — нормализованные и проверенные данные.
- **Gold** — аналитические модели и витрины.
