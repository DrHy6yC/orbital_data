# Orbital Data Platform

Lakehouse-платформа для сбора, хранения, обработки и анализа данных об
искусственных спутниках и других орбитальных объектах.

## Цель проекта

Собрать как можно более полный набор доступных данных из открытых источников,
сохранить оригиналы и историю изменений и обеспечить возможность повторной
обработки.

Проект также служит практической площадкой для развития навыков Data
Engineering: Python, SQL, PostgreSQL, Parquet, S3, DuckDB, dbt, Airflow.

## План и задачи

- [`PLAN.md`](PLAN.md) — десять этапов проекта с подэтапами, ожидаемыми
  результатами и статусами.
- [`BACKLOG.md`](BACKLOG.md) — задачи, которые выполняются сейчас, с порядком
  работы и способом проверки.

## Источники данных

- **CelesTrak** — TLE и OMM, открытый доступ.
- **Space-Track** — GP, GP_History, SATCAT, требуется регистрация.

Список источников [`catalog.md`](docs/data_sources/catalog.md)

## Технологический стек

- **Python 3.12+** — основной язык разработки.
- **uv** — управление зависимостями и окружением.
- **FastAPI** — REST API.
- **PostgreSQL** — метаданные и операционная информация.
- **MinIO (S3)** — хранение исходных данных.
- **Parquet / PyArrow** — аналитическое хранение.
- **DuckDB / dbt** — аналитическая обработка.
- **Apache Airflow** — оркестрация процессов.
- **SGP4** — орбитальные вычисления.

## Архитектура данных

Платформа использует архитектуру Lakehouse:

- **Bronze** — исходные данные без изменений.
- **Silver** — нормализованные и проверенные данные.
- **Gold** — аналитические модели и витрины.
